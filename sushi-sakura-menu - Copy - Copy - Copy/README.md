# Sushi Sakura Digital Menu

A static, mobile-friendly menu ready for GitHub Pages. Menu names, descriptions, prices, and categories are in `script.js`; the contact link is in `index.html`.

## Preview locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Create a GitHub repository named `sushi-sakura-menu`.
2. Upload this folder's contents to the repository.
3. On GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. Save. Your site will be available at `https://YOUR-USERNAME.github.io/sushi-sakura-menu/`.

Replace `https://wa.me/` in `index.html` with the restaurant's WhatsApp ordering URL or another ordering link.
